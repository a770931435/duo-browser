# V2 介面設計說明（2.0.0-beta）

## 方向：透紫機殼 ＋ 掌機主選單（A＋B）
- **對象**：用 RP Duo 掌機上網、看影片／漫畫的玩家；觸控和手把都要好用。
- **感覺**：像拿著紫透色機身——深色煙燻紫底、半透明紫色層疊、亮邊像塑膠殼的邊緣，隱約的格線像看得到的內部零件。
- **核心比喻**：選單就是一台掌機的系統選單：分頁是大卡片，功能是大顆按鈕，底部一列按鍵提示。

## 規則
- **色票全部在 `Theme.kt` 的 `T`**，畫面裡不寫死顏色（拿到實機照片後只改這裡）。
- **層級**：區塊標題（小、紫、字距寬）→ 卡片（同一組設定放一起）→ 列（左邊標題＋小說明，右邊控制項）。
- **控制項**：開關用切換鈕、數值用 − 值 ＋、進入下一頁用 ›；不再用「切換」文字按鈕和「：是／否」。
- **圖示**：一律用 `Icons` 畫的單色線條圖示，不用 emoji。
- **手把焦點**：亮紫外框＋放大 4%，動畫移動；觸控時沒有焦點框。
- **動畫**：曲線 `T.EASE`（快出慢停），一般 200ms、面板 260ms；按下縮到 96%；頁面切換時內容依序淡入上移。
- **減法**：說明文字只留一行；細節收進「ⓘ」或教學；按鍵說明只留底部提示列。

## 評審流程（每輪）
1. 在 RP Duo 截下屏：分頁、書籤、歷史、設定（上／中／下）、教學、上屏工具列。
2. 交給只看截圖的評審：美感、構圖、層級、字體、顏色、間距、細節一致性，挑最重要的 3 個問題並打分（0–10）。
3. 每輪只修前 3 個問題，最多兩輪；收斂不了就記下差距。
